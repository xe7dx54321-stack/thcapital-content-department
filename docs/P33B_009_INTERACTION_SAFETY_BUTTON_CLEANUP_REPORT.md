# P33B-009 Interaction Safety & Button Cleanup Report

## 目标

清理散落各处的按钮，明确哪些是真实执行、哪些是安全占位。

## 按钮分布原则

### 今日总览（4 个）
- 查看今日稿件
- 查看质量检查
- 刷新状态
- 手动补跑今日内容生产

### 今日稿件（内容相关）
- 复制正文
- 复制标题
- 标记为值得人工修改
- 标记为放弃
- 请求重写标题
- 请求换角度

### 系统运维（调试相关）
- 刷新系统状态
- 暂停 Runtime
- 恢复 Runtime
- 手动补跑今日内容生产
- 运行 Go-Live Acceptance
- 查看最新日志

## 安全占位机制

如果按钮后端没有真实执行能力，必须显示安全提示：

> 该操作已记录为待处理建议，暂未自动改写正式稿件。

**禁止伪装已经执行。**

## 危险按钮确认

以下操作必须有确认提示：
- 暂停 Runtime
- 恢复 Runtime
- 手动补跑今日内容生产
- 运行 Go-Live Acceptance

## 必须移除的散落按钮

- 首页不放暂停 Runtime / 恢复 Runtime
- 首页不放 OpenClaw 详情 / path-audit
- 首页不放 raw logs / replay raw data
- 今日稿件页不放系统运维相关按钮

## 安全边界

- 不自动发布公众号
- 不接微信公众号 API
- 不进入公众号草稿箱
- 不自动生成图片
- 不调用图片模型
- 不自动应用 calibration proposal
