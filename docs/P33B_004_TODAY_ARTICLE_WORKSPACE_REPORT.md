# P33B-004 Today Article Workspace Report

## 页面定位

用户真正读稿的地方。不能混入系统状态。

## 绝对不能出现

- Runtime PID
- LaunchAgent 状态
- OpenClaw conflict
- path-audit
- 7-day replay
- raw logs

## 页面结构

### A. 稿件头部

显示：
- 标题
- 副标题
- 主选题
- 生成时间
- 状态：待人工审阅 / 需要修订 / 暂缓
- 质量评级

### B. 人工判断卡片

显示：
- 是否值得读：是 / 否 / 待确认
- 是否可进入人工修改：是 / 否
- 主要优点
- 主要问题
- 建议修改方向

### C. 正文阅读区

- 排版像公众号文章预览
- 正文宽度约 720px
- 段落清晰
- 标题突出
- 正文旁边不放系统状态

### D. Agent 审稿意见

**默认折叠。**

默认只显示摘要：
- Agent 判断
- 核心问题
- 建议

展开后再显示：
- Proponent
- Critic
- Judge
- Rewrite

数据不足时显示"暂无详细审稿记录"，不报错。

### E. 内容操作按钮

只放内容相关按钮：
- 复制正文
- 复制标题
- 标记为值得人工修改
- 标记为放弃
- 请求重写标题
- 请求换角度

如果按钮后端没有真实执行能力，显示安全提示：
"该操作已记录为待处理建议，暂未自动改写正式稿件。"

## 数据来源

来自 `workbench_view_model.today_article`。
