# P33B-003 Today Overview / Command Center Report

## 页面定位

用户每天打开 Workbench 后默认看到的第一屏。

必须在 30 秒内回答：
- 系统今天正常吗？
- 今天有没有稿？
- 稿子值不值得看？
- 下一步该做什么？

## 页面结构

### A. 顶部状态条

字段：
- 今日状态：可审阅 / 等待生成 / 需要处理 / 系统异常
- 系统运行：正常 / 有警告 / 异常
- 候选稿：已生成 / 未生成 / 需要修订 / 暂缓
- 质量结果：通过 / 有警告 / 未通过 / 未检查
- 下一次自动运行

### B. 今日最终结论卡片

只展示最终结果，不展示过程。

字段：
- 今日主选题
- 推荐标题
- 一句话判断
- 为什么值得看
- 最大风险
- 建议动作

### C. 今日操作按钮

首页只放 4 个按钮：
- 查看今日稿件
- 查看质量检查
- 刷新状态
- 手动补跑今日内容生产

### D. 今日简要告警

最多 3 条。

没有严重问题时显示：暂无阻断问题。

## 设计原则

- 首页只显示结论，不显示过程日志
- 不出现 Runtime PID
- 不出现 path-audit
- 不出现 raw JSON
- 不出现 OpenClaw conflict 详情
- 不出现 Agent raw output

## 数据来源

来自 `workbench_view_model.today_overview`。
